## 🚀 كيف تستفيد من هذا المستودع وتطبق معنا؟

1. قم بعمل **Fork** للمشروع لإنشاء نسخة خاصة بك بالكامل على حسابك الشخصي في جيت هاب عبر رابط الحساب: [B2nd9R](https://github.com/B2nd9R).
2. استخدم برنامج **GitHub Desktop** لعمل **Clone** وسحب الملفات محلياً إلى جهاز الكمبيوتر الخاص بك.
3. عند دراسة أي حلقة، قم بفتح المجلد الفرعي الخاص بها مباشرة (مثل مجلد `01-Variables-DataTypes`) كشروع مستقل داخل بيئة **IntelliJ IDEA**، وذلك لكي يتعرف البرنامج على مسار الـ `src` تلقائياً ويعمل معك الكود بضغطة زر وبدون مشاكل.
4. حل التحدي المطلوب منك داخل مجلد `challenge` الموجود في حلقة اليوم، ارفع الحل على حسابك، وشاركنا رابط كودك في جروب التليجرام لنلقي عليه نظرة! 🔥
