# 🔒 تحدي الحلقة الأولى: إعدادات جدار الحماية (Firewall Setup)

تحدي المبرمجين الأول! 🚀 هنا بنطبق عملياً كل اللي تعلمناه في الحلقة الأولى حول **المتغيرات (Variables)** و**أنواع البيانات (Data Types)** في الجافا.

## 📝 المطلوب في التحدي:
تخيل أنك تبني جزء من نظام حماية، وتحتاج تحجز مكان في الذاكرة لتخزين إعدادات جدار الحماية (Firewall). مطلوب منك إنشاء **3 متغيرات** في كودك باستخدام أنواع البيانات الصحيحة بالملي:

1. **اسم السيرفر:** متغير نصي (`String`) يخزن اسم الخادم المستهدف (مثال: `"Main-Auth-Server"`).
2. **رقم المنفذ (Port):** متغير رقمي صحيح (`int`) يخزن رقم البورت المفتوح للاتصال (مثال: `443` أو `8080`).
3. **حالة جدار الحماية:** متغير منطقي (`boolean`) يوضح هل الحماية مفعّلة أو لا (قيمته تكون يا `true` يا `false`).

---

## 🖨️ المخرجات والطباعة:
بالنسبة لطريقة الطباعة وشكل المخرجات في الـ Console.. **الموضوع راجع لكم وبكيفكم تماماً!** صمم لوحة البيانات واطبعها بالشكل والفخامة اللي تشوفها مناسبة وتناسب ذوقك. 

أهم شيء في التحدي وأساس التقييم هو إنك تكون **منفذ ومطبق الثلاث شروط الأساسية فوق** داخل الكود ومستخدم أنواع البيانات الصح.

انطلقوا وورونا إبداعاتكم وتصاميمكم في جروب التليجرام! 🔥
