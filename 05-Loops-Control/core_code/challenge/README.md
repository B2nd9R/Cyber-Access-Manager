# ⚙️ تحدي الحلقة الخامسة: ماسح الثغرات والمنافذ التلقائي (Automated Vulnerability Scanner)

تحدي المبرمجين الخامس! 🚀 هنا بننقل نظامنا الأمني **Cyber Access Manager** لعصر الأتمتة المطلقة، وبنطبق عملياً كل اللي تعلمناه حول **الحلقات التكرارية (Loops)** وكيف نصنع آلة برمجية ذكية تفحص مئات البيانات والمنافذ بأسطر كود معدودة بداخل لغة الجافا.

---

## 📝 سيناريو التحدي والمطلوب:
تخيل أنك تطور أداة فحص أمني تلقائية (Scanner) لسيرفرات منشأة حساسّة، وبدل ما تكتب كود فحص المنافذ الشبكية (Ports) يدوياً بمليار سطر، بتكتب محرك ذكي يمر عليها بورت بورت تلقائياً في الذاكرة العشوائية RAM، ويحللها ويصيد الثغرات والمنافذ المفتوحة لايف.

افتح ملف `VulnerabilityScanner.java` المرفق مع هذا التحدي، والمطلوب منك تكمله برمجياً كالتالي:

1. **حلقة الفحص الشامل (For Loop):** أنشئ حلقة تكرارية `for` تبدأ من المنفذ رقم `1` وتنتهي عند المنفذ رقم `100` (`port <= 100`).
2. **رصد المنافذ المفتوحة (If Condition inside Loop):** بداخل كل لفة، اجعل النظام يطبع رسالة فحص اعتيادية لكل بورت (مثال: جاري فحص البورت رقم X...). ولكن! باستخدام جملة شرطية بداخل الـ Loop، إذا كان رقم البورت الحالي يساوي `22` (منفذ الـ SSH) أو يساوي `80` (منفذ الـ HTTP)، اطبع تحذير أمني خاص بلون مختلف (🚨 تنبيه: رصد منفذ مفتوح وثغرة محتملة!). *(استخدم معامل الـ OR المنطقي `||` للربط بين المنفذين).*
3. **كسر الحلقة عند الخطر الحرج (The Break Keyword):** إذا وصل عدّاد الفحص إلى المنفذ رقم `88` (بورت حرج جداً)، ارفع حالة الطوارئ القصوى، واطبع رسالة تفيد بإغلاق الجلسة فوراً، ثم اكسر الحلقة التكرارية تماماً واخرج منها باستخدام أمر المحترفين `break;`.

### 💡 تريكة برمجية حاسمة (كواليس الـ الذاكرة):
> تذكر دائماً قوة الكلمة المحجوزة `break;` بداخل الجافا! هذي الكلمة بمجرد ما يقرأها معالج الكمبيوتر بداخل أي حلقة تكرارية، يقفز مباشرة إلى خارج أقواس الـ Loop ويوقف التكرار فوراً، حتى لو كان عدّاد اللفات باقي ما وصل لنهايته (المنفذ 100)!
> هذي الحركة تسمى في كواليس هندسة البرمجيات بالإنهاء المبكر (Early Termination)، ونستخدمها لحماية موارد المعالج (CPU) والذاكرة العشوائية من الهدر بمجرد أن يحقق البرنامج هدفه الأساسي أو يرصد خطراً حرجاً يتطلب التدخل الفوري.

---

## 🖨️ المخرجات والطباعة:
بالنسبة لطريقة هندسة المخرجات وشكل سجلات ماسح الثغرات (Scanner Logs) في الـ Console عند تشغيل البرنامج.. **الموضوع راجع لإبداعكم وذوقكم الفخم كالعادة!** صممها بالشكل التقني اللي تشوفه مناسب؛ خل المخرجات تتدرج من فحص عادي، إلى تحذيرات عند بورت 22 و 80، ثم رسالة إغلاق السيرفر الكبرى عند بورت 88 وتوقف البرنامج، بشكل يثبت أنك مهندس برمجيات فاهم ومحترف.

---

## 🚀 كيف تشارك حلك؟
1. انسخ الكود المرفق، وافتحه بداخل برنامج **IntelliJ IDEA**.
2. فكر في المنطق البرمجي، واكتب الـ `for` loop وبداخلها جدران الفحص الشرطية وتكتيك الـ `break`.
3. صور شاشة المخرجات (الـ Console) كاملة لترى كيف توقف الفحص تلقائياً عند البورت 88، وشارك لقطة الشاشة أو كودك النهائي معنا بداخل **مجتمع التليجرام** عشان نتناقش فيه ونشوف إبداعات وحوش الأتمتة! 🔥
